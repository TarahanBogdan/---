# SocialGram 📱

Сучасна соціальна мережа, що поєднує найкращі функції Instagram та Telegram в одній платформі.

## 🌟 Особливості

### Instagram-подібні функції:
- 📸 Завантаження фото та відео
- 📱 Стрічка новин з постами
- 👥 Система підписників та підписок
- ❤️ Лайки та коментарі
- 📊 Історії (Stories)
- 🔍 Дослідження та популярні пости
- 👤 Профілі користувачів з біографією
- 🏷️ Теги та геолокація

### Telegram-подібні функції:
- 💬 Реал-тайм чат з підтримкою текстових повідомлень
- 📁 Відправка файлів та медіа
- 👥 Групові чати
- 📢 Канали
- ✏️ Редагування повідомлень
- 😀 Реакції на повідомлення
- 🔔 Сповіщення в реальному часі
- 👀 Статус "в мережі"

### Технічні особливості:
- 🔐 JWT автентифікація
- 📱 Адаптивний дизайн
- 🌙 Сучасний UI з Material-UI
- ⚡ WebSocket для реал-тайм функцій
- 📦 Завантаження файлів в хмару (Cloudinary)
- 🛡️ Валідація та безпека
- 📊 MongoDB база даних

## 🚀 Швидкий старт

### Передумови
- Node.js (версія 16 або вище)
- MongoDB (локально або Atlas)
- npm або yarn

### Встановлення

1. **Клонуйте репозиторій:**
```bash
git clone <repository-url>
cd socialgram
```

2. **Встановіть залежності:**
```bash
npm run install-deps
```

3. **Налаштуйте змінні середовища:**

Створіть файл `.env` в папці `server`:
```env
NODE_ENV=development
PORT=5000
CLIENT_URL=http://localhost:3000
MONGODB_URI=mongodb://localhost:27017/socialgram
JWT_SECRET=your_super_secret_jwt_key
JWT_EXPIRES_IN=7d
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
```

Створіть файл `.env` в папці `client`:
```env
REACT_APP_API_URL=http://localhost:5000/api
REACT_APP_SERVER_URL=http://localhost:5000
```

4. **Запустіть MongoDB:**
```bash
# Локально
mongod

# Або використовуйте MongoDB Atlas (хмарна версія)
```

5. **Запустіть програму:**
```bash
# Запуск і фронтенду, і бекенду одночасно
npm run dev

# Або окремо:
npm run server  # Бекенд (порт 5000)
npm run client  # Фронтенд (порт 3000)
```

6. **Відкрийте в браузері:**
```
http://localhost:3000
```

## 🛠️ API Ендпоінти

### Автентифікація
- `POST /api/auth/register` - Реєстрація
- `POST /api/auth/login` - Вхід
- `GET /api/auth/me` - Поточний користувач
- `POST /api/auth/logout` - Вихід

### Користувачі
- `GET /api/users/search` - Пошук користувачів
- `GET /api/users/:username` - Профіль користувача
- `PUT /api/users/profile` - Редагування профілю
- `POST /api/users/:id/follow` - Підписатися/відписатися

### Пости
- `GET /api/posts` - Стрічка постів
- `POST /api/posts` - Створити пост
- `GET /api/posts/:id` - Отримати пост
- `POST /api/posts/:id/like` - Лайкнути пост
- `POST /api/posts/:id/comment` - Додати коментар

### Повідомлення
- `GET /api/messages/:chatId` - Повідомлення чату
- `POST /api/messages` - Відправити повідомлення
- `PUT /api/messages/:id` - Редагувати повідомлення
- `DELETE /api/messages/:id` - Видалити повідомлення

### Чати
- `GET /api/chats` - Список чатів
- `POST /api/chats/direct` - Створити приватний чат
- `POST /api/chats/group` - Створити групу
- `POST /api/chats/channel` - Створити канал

## 🔧 Налаштування Cloudinary

1. Зареєструйтеся на [Cloudinary](https://cloudinary.com/)
2. Отримайте ваші API ключі з Dashboard
3. Додайте їх в файл `.env` сервера

## 📱 Функції для користувачів

### Реєстрація та вхід
1. Відкрийте http://localhost:3000
2. Натисніть "Зареєструватися"
3. Заповніть форму реєстрації
4. Увійдіть з вашими даними

### Створення постів
1. Натисніть "Створити пост" в бічній панелі
2. Додайте текст, фото або відео
3. Додайте теги та локацію (опціонально)
4. Оберіть видимість поста
5. Натисніть "Опублікувати"

### Відправка повідомлень
1. Перейдіть в розділ "Повідомлення"
2. Виберіть існуючий чат або створіть новий
3. Введіть текст повідомлення
4. Натисніть Enter або кнопку відправки
